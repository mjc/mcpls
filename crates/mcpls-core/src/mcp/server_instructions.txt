Use MCPLS for every source read, search, diagnostic, symbol relationship, and semantic edit. Register the repository with project_add and wait for project_activate to report Ready before discovery; an empty result while activation is loading is not authoritative. Start unknown symbols with exact-first workspace_symbol_search; its source frames and symbol_handle are safe inputs to handle-aware follow-ups. Use inspect_symbol for a bounded definition, implementation, references/calls, tests, and diagnostics bundle. Set section and byte/item budget fields explicitly for tighter context. Never silently choose an ambiguous candidate. On stale_symbol_handle, rerun discovery and use the replacement handle. When a result contains a deferred resource URI, read it with resources/read or, when that protocol method is unavailable as a callable client feature, read_semantic_resource. Direct file reads and shell search are only for an exact path or non-source artifact after MCPLS has identified the implementation slice.
`get_server_logs` and `get_server_messages` expose buffered LSP traffic; they are not MCPLS process logs. Process diagnostics and request traces remain on stderr.
